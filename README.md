Personal Expense and Budget Tracker.

## Status

Repository scaffold only.

PocketWise screens, backend features, migrations, deployment,
and backup scripts still need implementation.

## Planned stack

- Flutter and Dart
- Python and FastAPI
- PostgreSQL and SQLAlchemy
- Alembic
- Flutter local notifications

## Planned features

- Registration, login, and logout
- Income and expense management
- Category management
- Monthly dashboard
- Category budgets and warnings
- Search and filters
- Charts and monthly reports
- Bill reminders
- Quick-entry templates
- Profile and password settings

CSV export is excluded.

## Run the Flutter starter

From the frontend directory:

    flutter pub get
    flutter devices
    flutter run

Start an Android emulator or connect an Android phone first.

## Backend

Not runnable yet. Complete the Python implementation and
